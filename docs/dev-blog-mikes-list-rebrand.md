# Mike's List: A Broader Local Listings Project

I have renamed the project from Bay Area Show Explorer to Mike's List.

That sounds like a branding decision, and it is, but it also reflects a real shift in what the site is trying to become. The project started as a way to make imported Bay Area music listings easier to browse. That is still important. Show Explorer remains the first core tool, and music is still the center of gravity. But the more I worked with the data, the more obvious it became that venue life is bigger than artist listings.

A local calendar has to know what to do with karaoke, trivia, poetry nights, open mics, cover bands, game nights, dance parties, and strange one-off events that do not fit neatly into a music database. Treating all of those as artists makes the public site worse and makes the admin workflow harder to trust. Ignoring them makes the calendar less useful. Mike's List gives the project room to handle that middle ground.

The new philosophy is simple: a listing is a show first. Some shows are artist shows. Some shows are event shows. Both can belong on the site, but they should not be forced into the same shape.

That model has already changed the way the app works. Show Review can now separate music listings from non-music events, edit display names, store image links, preserve source links, merge duplicates, and feature selected records as Mike's Picks. Artist and venue review are becoming more practical too, with better filtering by date, source, venue, and review need. The goal is not just to collect more data. The goal is to make it possible to verify a useful slice of local culture without losing the context that came from the original source.

The public side is changing as well. The default Show Explorer feed can stay focused on music, while other event types remain available through filters. That lets the site be useful to someone looking for concerts tonight without closing the door on someone looking for karaoke, trivia, or a low-key open mic.

The source strategy is also broadening. The List is still a strong music source, and KALX adds curated weekly coverage. Neither source is perfect, but together they create a more textured picture of what is happening around the Bay Area.

This rebrand also gives the project a better future shape. Mike's List can contain Show Explorer, source pages, venue pages, artist pages, featured picks, admin tools, and later maybe other local guides that are not strictly show calendars. The name is personal enough to admit that judgment is part of the product. This is not a neutral machine pretending to know everything. It is a tool for making messy local information more useful.

Recent wins:

- The project now has a clearer umbrella identity: Mike's List.
- Show Explorer becomes one offering inside that larger project.
- Shows can be reviewed as music listings or non-music event listings.
- Event types and themes are becoming real user-facing filters.
- Mike's Picks creates an editorial path for featured listings.
- Public pages can stay clean while admin pages preserve richer review context.

The next phase is about making the brand and architecture match the ambition. That means updating the visible site language, tightening the admin workflow, and continuing to split large data stores into lighter public bundles. The project is still a prototype, but it now has a better name for the thing it is becoming.
